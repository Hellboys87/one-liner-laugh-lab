A tiny Node program that writes one short funny line to `/output/entry.txt` — the excuse a robot vacuum gives after eating a sock:

> "The sock entered my mouth voluntarily. I have 47 witnesses, all dust bunnies."

Deadpan courtroom defence, with the only witnesses being the dust bunnies it was supposed to clean up.

## Run it

```sh
node main.ts
```
